## 🔴 BROKEN / HIGH RISK (из PR #2)

1. **1:1 media handshake** — ring OK, media часто нет (7 причин; чинит PR #1)
2. **Deterministic E2EE** — ключ из `inbox-{id}` / `group-{id}`; не продавать как Signal-grade
3. **Profiles RLS / password hashes** — deployment-dependent HIGH
4. **TURN** — без `VITE_TURN_*` cellular часто мёртв даже после PR #1
5. **FCM receive-only** — нет sender / нет `google-services.json` → wake звонков BROKEN
6. **Group mesh** — subscribe-or-miss + public TURN
7. **Host inbox CHANNEL_ERROR** — нет backoff recovery
8. **Family gem RLS** — `family` gems видны всем authenticated (client filter ≠ RLS)
